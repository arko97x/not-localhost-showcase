## Where your work goes

You have a folder named after you. Inside it, one folder per task, and one folder per iteration:

```text
ram-kumar/
└── task-01/
    ├── iteration-01/
    └── iteration-02/
```

Keep earlier iterations. Progress matters more than polish.

## Getting set up

Do this once.

1. Create a [GitHub account](https://github.com/signup).
2. Send your GitHub username to Arko.
3. Accept the collaborator invitation GitHub emails you.
4. Install [GitHub Desktop](https://desktop.github.com), sign in, and choose **File → Clone Repository** to clone this repository.

## Sharing your work

In GitHub Desktop:

1. Click **Fetch origin**, then **Pull origin** to get the latest work.
2. Use **Repository → Show in Finder** (or **Show in Explorer**) to open the repository, then add your files in your next iteration folder.
3. In the **Changes** tab, check that only files in your folder are selected. Add a short summary, then click **Commit to main**.
4. Click **Push origin**. If it asks you to pull first, click **Pull origin**, then push again.

## Ground rules

- Work only inside your own folder.
- Never commit passwords, API keys, or `.env` files.
- Don’t commit `node_modules/` or build output.
