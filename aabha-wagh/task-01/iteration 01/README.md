# READER — Digital Counterpart

Static prototype of the digital archive/repair layer around the physical Reader.

## Run locally

No dependencies are required.

Option 1: open `index.html` directly.

Option 2:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — homepage / archive entrance
- `reader.html` — DAC-04 device page
- `styles.css` — visual system
- `script.js` — interactions
