# VEND YOUR SIMULATION — vending flow

Flow:
1. Drag to rotate.
2. Scroll/pinch to zoom.
3. Click a can.
4. The can slides forward and drops into the collection tray.
5. Click the dispensed can.
6. Its safe local demo page opens.
7. Return to the vending machine.

Replace demo-01.html through demo-13.html in index.html with the students' actual GitHub Pages/live URLs later.

Three.js and OrbitControls load from jsDelivr, so internet access is needed when opening index.html directly.
